# 产品行为

本文定义任务状态、角色反馈与桌面交互；实现结构见[架构说明](architecture.md)，实际验证范围见[验收清单](acceptance.md)。

## 1. 定位与使用场景

“AI 娘值班室”是自己维护的 DSH 桌面宠物插件。用户切到编辑器、浏览器或最小化 DSH 后，仍能通过角色身边的气泡了解正在执行哪些任务、执行到哪一步，以及何时需要回来处理。

目标平台为 Windows 与 macOS。桌面悬浮与全局任务展示是核心能力。

## 2. 功能范围

| 模块 | 行为 |
| --- | --- |
| 独立实现 | 自己维护宿主插件、桌面程序、动画、状态机与设置；使用 DSH 官方接口 |
| 桌面显示 | 独立透明窗口，置于普通应用窗口之上；DSH 最小化、隐藏或被遮挡时继续显示与更新 |
| 任务覆盖 | 当前 DSH 宿主实例内所有运行会话，包含未打开的会话；子任务聚合到父任务 |
| 执行气泡 | 显示真实任务名称、执行阶段、简短执行对象和可用的耗时信息 |
| 状态反馈 | 区分运行、等待审批、等待输入、本轮结束、最终失败、手动停止、闲置 |
| 角色 | DeepSeek 鲸娘、GPT 龙娘、Claude 娘、Grok 娘、Gemini 双子猫娘；各常态与 Q 版 |
| 动画 | 闲置呼吸/眨眼、持续工作循环及适量状态动作；注视交互不冻结工作循环 |
| 基础操作 | 拖动、缩放、角色与形态选择、固定/轮换、隐藏气泡、位置与偏好记忆 |
| 任务跳转 | 用户主动点击气泡后恢复 DSH 并定位对应会话 |

功能围绕当前 DSH 实例的任务展示与角色陪伴，不包含养成经济、商店、每日任务、Live2D、语音、独立聊天、自动按模型换角色和跨实例任务聚合。

## 3. 运行信息与角色文案

| 状态 | 气泡信息 | 角色文案 |
| --- | --- | --- |
| 运行中 | 任务名、真实执行阶段、工具/文件/命令摘要、可用耗时 | 不显示；点击或悬停也不插入闲聊 |
| 等待审批 | 任务名、需要审批的操作、返回会话入口 | 不显示玩笑，优先处理事项 |
| 等待输入 | 任务名、等待回答/补充的内容摘要 | 不显示玩笑，优先处理事项 |
| 本轮正常结束 | “本轮结束 / 结果待查看”等真实结论 | 可以短暂显示一条对应角色文案 |
| 最终失败 | 明确的终止状态和简短原因 | 可以附一条失败文案，不遮住原因 |
| 手动停止 | “已停止”，与失败分开 | 可以短暂显示停止文案 |
| 全部闲置 | 无运行任务，默认收起任务气泡 | 按低频策略显示闲置文案 |

运行气泡示例：

```text
修改插件设置页
正在读取 · settings.ts
已运行 02:18
```

“正在读取”等阶段必须由真实执行事件得出；拿不到具体阶段时显示“运行中”。没有可信开始时间时省略耗时。不得按定时器编造阶段、完成比例或剩余时间。

单次工具报错但任务继续执行，仍属于运行态；只有任务确实终止失败才展示失败反馈。本轮结束只表示这一轮执行完成，不自动宣称用户目标全部达成。

## 4. 多任务展示

- 每个主任务保留自己的状态与摘要，子任务归属父任务，避免气泡重复堆叠。
- 同时运行多个任务时，展示紧凑任务组；超过显示空间时折叠为“还有 N 个任务”，可主动展开。
- 等待用户处理的任务优先可见；其余任务顺序保持稳定，避免每条工具事件都让列表跳动。
- A 任务仍运行、B 任务结束时：A 继续显示执行事实，B 可短暂显示结束反馈；宠物总体继续工作，不进入闲置。
- 消息不会抢键盘焦点。只有用户主动点击任务时，才恢复并切换 DSH 会话。

默认展示最多三个主任务；结束结果保留约 12 秒。宿主合并未变化的快照，桌面单独更新耗时标签。

## 5. 角色与动画

5 位角色共 10 种形态，保留各自的面部、眼睛、服饰和标志特征。素材格式和动画状态映射见[角色素材](assets.md)。

支持手动切换、固定当前角色、顺序轮换、收藏轮换与随机轮换；随机轮换避免连续重复。轮换间隔为 1–3600 秒，默认 10 秒；手动选择形态后切回固定模式。

任务持续执行时持续播放工作循环，不能仅在收到事件的一瞬间播放动作。闲置也有可见但克制的动态。拖动与注视是独立交互，不应让角色长时间僵住。静态图或精灵图不按 Live2D 模型处理。

文案按角色和状态管理，保留原有语气与角色差异；GPT 的脑洞/自信/长回答梗、Gemini 的双子/猫娘特点优先于单一重复梗。原文语气词与标点需完整保留。

## 6. 桌面行为

- 宠物与气泡属于独立桌面窗口，DSH 主窗口最小化不影响显示。
- 透明空白区域允许点击下层应用，宠物和气泡的操作区域正常响应。
- 不因执行事件主动抢焦点或弹回 DSH。
- 支持拖动与多显示器位置记忆；显示器变化后位置落在可见区域内。
- 默认随插件启用而启动；DSH 真正退出或插件停用时释放窗口与连接。主窗口隐藏不等于宿主退出。
- 面向普通桌面窗口使用；系统安全桌面和独占全屏不在悬浮支持范围内。

## 7. 与现有产品的关系

项目独立维护宿主插件、桌面程序与角色策略，使用 DSH 官方插件接口，不修改 DSH 安装包，也不依赖现成第三方桌宠插件。
