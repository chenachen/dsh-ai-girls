# 角色素材与文案接入

## 来源

用户已有的“制作 AI 娘宠物形象初稿”任务提供角色图与动画素材，以及角色文案库。本项目在接入阶段复用已确认的版本，保持自有插件实现。

| 角色 | 形态 | 识别重点 |
| --- | --- | --- |
| DeepSeek 鲸娘 | 常态、Q 版 | 鲸娘特征与蓝色视觉体系 |
| GPT 龙娘 | 常态、Q 版 | 龙娘特征与角色标志 |
| Claude 娘 | 常态、Q 版 | 独立面部、配色与角色标志 |
| Grok 娘 | 常态、Q 版 | 独立面部、配色与角色标志 |
| Gemini 双子猫娘 | 常态、Q 版 | 双子、猫娘识别特征 |

## 已有材料与选择原则

- `native-pets/`：10 种形态与原有状态动画素材，可作为接入候选。
- `pet-motion-v2/`：动作优化产物。原任务仍可能更新，接入前检查实际版本和预览，不直接将中间结果定为发布素材。
- `desktop-pet/characters.json`、`desktop-pet/台词库.md`：前期读取过的 360 条角色文案来源；接入时核对当前文件，按状态重组。
- 较早的 `角色与状态文案.json` 与后续文案存在内容差异，不自动覆盖新文案。

这些名字是原任务输出目录中的相对路径，当前仓库尚未复制图片、动画或原始文案。机器上的来源路径记在不提交的 `LOCAL_SETUP.md` 中。

## 接入要求

1. 为每个角色和形态确定稳定 ID，记录素材版本、来源与预览。
2. 只迁移本项目实际使用的文件；每次更新可追踪，不整包复制工作缓存和历史安装包。
3. 文案映射遵循产品方案：运行期间不取闲聊文案；等待审批/输入优先事实提示。
4. 保留用户原文的语气词、标点和角色边界，不擅自添加角色或将猫娘设定替换成单一香蕉梗。
5. 核对透明通道、帧布局、动画时长和桌面缩放后的观感；记录实际授权/来源情况后再考虑公开发行。

素材发布方式、二进制体积管理和最终许可证在实际接入/发行阶段确定。
